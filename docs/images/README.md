# SPCG site images

Drop your photos here using these folders. The site loads them automatically — no code changes needed.

| Folder | What to add |
|--------|-------------|
| `hero/` | Main hero, truck, framing shots |
| `team/` | **sam-patel.jpg** (About page portrait), crew photo, branding |
| `gallery/` | `01`–`06` project highlights (see `src/lib/images.ts`) |
| `site/` | On-the-job strip photos `01`–`05` |
| `projects/` | Portfolio cards |
| `services/` | One image per service line |
| `testimonials/` | Client headshots (optional) |

**Tips:** JPG or WebP, at least 1200px wide for large slots. Use the exact filenames in `src/lib/images.ts` and `src/lib/site.ts`.
