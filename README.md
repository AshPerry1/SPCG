## Fix: live link shows this markdown or 404

Open **[github.com/AshPerry1/SPCG/settings/pages](https://github.com/AshPerry1/SPCG/settings/pages)** and set **one** of these:

| Source | Branch | Folder |
|--------|--------|--------|
| **Deploy from a branch** (easiest) | `main` | **`/docs`** |
| **Deploy from a branch** | `gh-pages` | **`/ (root)`** |

Do **not** use branch `main` with folder **`/` (root)** — that publishes this README instead of the site.

Save, wait 2–3 minutes, then hard-refresh (`Cmd+Shift+R`).
