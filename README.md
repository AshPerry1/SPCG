### If the live link shows this markdown instead of the site

1. Open **[Settings → Pages](https://github.com/AshPerry1/SPCG/settings/pages)**
2. Set **Source** to either:
   - **GitHub Actions** (recommended), or
   - **Deploy from a branch** → Branch `main` → Folder **`/docs`**
3. Do **not** use folder **`/` (root)** — that publishes this README as the homepage.
4. Save, wait 2–3 minutes, then hard-refresh the site (`Cmd+Shift+R`).

Every push to `main` rebuilds the site in `docs/` automatically (except commits that only touch `docs/`).
